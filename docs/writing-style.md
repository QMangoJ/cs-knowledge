# 讲解写作标准（2026-11-17 定版）

来源：Daniel 与 Gemini 的分布式对话（他亲自发来要求学的表达）+ 站内既定标准（先场景、再定义、再讲代价、再讲谁在用）。以后所有课文新写、重写、验收都按这份标准。核心一句话：**读者读完要能把机制在脑子里跑一遍，并带走一句能复用的判断。**

## 八条

1. **一个场景贯穿到底**：每课（或每个机制）选一个具体场景立住——东京与法兰克福两台机器、余额 100 变 0、海底光缆断掉的那十分钟——后面每个抽象点都回到这个场景里兑现。不许换着例子讲同一个点，更不许抽象复述。
2. **结论先行**：每步开头第一句就把这步的结论说死（「CAP 讲的其实就一件事：断网那十分钟被迫做的二选一」），再展开。标题也要带结论，不用空泛的主题词。
3. **数字走一遍**：凡是计数、编号、概率、时序，必须拿具体数字实际走一遍给读者看（Lamport：A 走到 2、B 在 1，消息带 2 过去，B 被顶到 max(1,2)+1=3）。只描述规则不走数字，等于没讲。
4. **比喻必须干活**：比喻要和机制 1:1 对应（总指挥定规矩 vs 具体武器、信封上贴计数、全员进度表），一个比喻立住就一直用它，不另起新的。不干活的修辞删掉。
5. **一个事实只讲一次，靠指路不靠复述**：同一结论在全课只出现一次权威版；其他地方要提到，用一句话指回那一步（「第 4 步讲过的信封机制」），不许在 premise/导读/tldr/正文/概况之间换着说法重复。概况四件套分工：premise 只留场景，导读独占结论，定位只讲本课在全图的位置，overview 只做速览表。
6. **结尾给可带走的东西**：每课（或每个大机制）收尾要有一句口诀、一张对照表或一个决策三问——读者能背下来、面试能直接用的那种。散文式总结不算收尾。
7. **真实工程落地**：谁在用，要点名真实系统和它真实的做法（微信红包的核心账本 CP + 外围 AP、银行 ATM 的离线限额 + 夜间对账、Spanner 的海底光缆 + 原子钟），不许只写「大厂都在用」。
8. **预判读者的漏洞问题**：写的时候站在读者座位上想「这里他会卡在哪」——比如「两台机器从不发消息，Lamport 凭什么排先后？」——把这个反问和解答写进讲解里，而不是等读者自己困惑。

## 反面清单（出现即打回）

- 同一意思换个说法讲第二遍（包括 tldr 预告全文、步尾总结前文、步首复述上一步）。
- 一句话套三层从句；一段话一个句号。
- 「也就是说」「换句话说」后面跟的还是刚才那句话。
- 只给定义和结论，不给场景、不走数字。
- 口号式凝练（正常日常表达，Daniel 2026-11-16 定）。

## 提问路径 = 课文骨架（2026-11-17 Daniel 补）

Daniel 与 Gemini 那段对话里，他的提问顺序本身就是一套理解一个概念的完整路径。课文组织和答疑都按这条链走：

1. **本质**：先用大白话一句话说清这到底是件什么事。
2. **机制走一遍**：拿场景和数字实际跑一遍。
3. **边界**：极端情形怎么办？有没有「全都要」的场景？规则在哪失效？
4. **关系**：它和已学过的概念是什么关系——上下级、互补，还是平行取舍？谁决定谁？
5. **反例质疑**：拿最刁钻的情形质疑机制本身（两台机器从不发消息，凭什么排先后？），把解答写出来。
6. **实务选型**：真实工程里按什么标准选它、选它的对手，点名真实系统。
7. **体系串联**：最后把整课（一节）逻辑用一段话或一张图串起来，确认每块的位置。

答疑时的思路同理：先定位他真正问的点，一句话给结论，再走场景；主动补上与之紧相连、他下一个就会问的那一层；结尾收成口诀、表或关系图。

## 具象化三件套（2026-11-17 夜补，来自 Daniel 完整对话记录）

Daniel 追问一个概念时，必问三件事，课文要提前写好，不等他问：

1. **形态**：这个东西以什么形式存在——独立进程、代码库（SDK）、还是配置文件？在哪台机器上跑？长什么样？（他的原话：「这些是什么形式存在的啊，是自己写的代码仓库吗」）
2. **来源**：谁做的、什么时候、被什么痛逼出来的。（Kafka 出自 LinkedIn、K8s 出自 Google 的 Borg——这类出处他必问。）
3. **前端对应物**：这个概念在前端世界有没有同构的东西（多 Tab 选主 ≈ Raft、防重 Token ≈ 幂等键、乐观更新 ≈ AP + 补偿）。有就写出来，这是他理解新概念最快的桥。

## 验收方法

改完一课，逐条自查：①场景是不是一个贯穿的；②每步第一句是不是结论；③该走的数字走没走；④全文搜一遍，有没有哪个结论出现两次以上；⑤结尾有没有口诀/表/三问；⑥字数比改前降了多少（只砍重复，不砍事实，目标降 10–20%）。
